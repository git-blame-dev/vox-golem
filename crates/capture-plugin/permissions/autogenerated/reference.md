## Default Permission

Allows access to all capture plugin operations.

#### This default permission set includes the following:

- `allow-snapshot`
- `allow-enable-capture`
- `allow-list-captures`
- `allow-select-notes-folder`
- `allow-play-capture`
- `allow-stop-playback`
- `allow-retry-capture`
- `allow-finalize-capture`
- `allow-update-transcript`
